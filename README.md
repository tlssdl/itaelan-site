# IT태란 스터디 플래너

공부할 내용을 자유롭게 적고 날짜와 진도를 관리하는 독립적인 개인 플래너입니다. 미리 정해진 학습 항목이나 필수 분류 없이 빈 계획에서 시작합니다.

## 사용

- 첫 화면에서 공부할 내용과 날짜를 입력하면 바로 계획을 추가합니다. 날짜를 비우면 ‘날짜 미정’에 보관합니다.
- 주간 계획, 전체 계획, 날짜 미정으로 볼 수 있습니다. 주간 보기의 날짜 버튼으로 하루만 확인할 수 있습니다.
- 계획을 누르면 제목, 날짜, 자유 입력 분류, 상태, 다음 할 일·메모, 자료 링크·파일 위치를 수정합니다.
- 같은 제목으로 만든 계획도 날짜와 진도를 독립적으로 관리합니다.
- 노션 등의 HTTP(S) 링크는 새 탭에서 열고, 로컬 파일 위치는 복사합니다. 문서 파일은 업로드하지 않습니다.
- 휴지통으로 옮긴 계획은 기록을 유지하며 복원할 수 있습니다. 영구 삭제 기능은 없습니다.

## 저장과 이전

현재 도메인의 브라우저 localStorage에 저장합니다. 로그인·서버 동기화는 없으며, 백업 저장·불러오기로 기기 사이에 옮길 수 있습니다. 브라우저 데이터를 지우기 전에 백업을 보관하세요. 백업은 공개 저장소에 커밋하지 마세요.

독립 플래너는 `itaelan.free-study-planner.v2` 키를 사용합니다. 이전 `itaelan.study-planner.v1` 데이터는 삭제하거나 덮어쓰지 않습니다. 처음 열 때 새 데이터가 없으면 사용자가 추가·선택·기록한 항목만 독립 계획으로 가져옵니다. 입력하지 않은 기본 항목은 생성하지 않습니다. 주간 선택만 있던 항목은 해당 주의 월요일에 배치하며, 그 주 안에 목표 날짜가 있으면 목표 날짜를 사용합니다. 이전 별도 기록은 편집 화면의 ‘이전 기록’에 보관합니다.

`legacy-*` 파일은 이전 기록과 백업을 읽기 위한 호환 모듈입니다. 새 사용자에게는 불러오지 않으며 화면의 계획 생성·분류·진도와 연결되지 않습니다.

## 개발과 배포

런타임 패키지 의존성 없는 HTML/CSS/JavaScript 앱입니다.

- `npm run dev`: 로컬 실행
- `npm test`: 독립 상태·날짜 이동·백업·휴지통·이전 데이터 변환 검증
- `npm run build`: 배포 파일을 dist에 새로 생성

Vercel이 main 브랜치의 변경을 배포합니다. 기존 화면은 Git 기록으로 복구할 수 있습니다.

## 월간 캘린더

첫 화면은 큰 월간 캘린더입니다. 공부와 일반 일정은 별도 종류로 나누지 않고 같은 계획 데이터로 관리합니다. 기존에 날짜를 지정한 계획도 그대로 표시됩니다. 날짜 또는 빈칸의 ＋를 누르면 해당 날짜로 입력창을 열고, 일정 제목을 누르면 수정합니다.

월 이동, 연월 직접 선택, 오늘로 이동, 하루 일정 목록과 월 전체 목록을 지원합니다. 날짜마다 3개까지 표시하고 더 많은 항목은 ‘더 보기’로 확인합니다. 모바일에서는 큰 날짜 칸을 유지하며 가로 스크롤합니다.

시작·종료 시간과 장소를 선택적으로 기록합니다. 시간이 없으면 종일로 표시합니다. 종료 시간은 같은 날의 시작 시간 이후여야 합니다. 시간·장소는 기존 브라우저 저장과 백업에 포함되며, 이전 백업은 시간 없는 일정으로 읽습니다.
