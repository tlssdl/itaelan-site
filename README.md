# IT태란 학습 플래너

www.itaelan.cloud의 개인 학습 계획 화면입니다. 기존 정원 페이지를 주간 계획과 네트워크·시스템 로드맵으로 교체합니다.

## 사용

- 로드맵 항목을 선택한 주에 담습니다. 각 항목의 시작 전 / 공부 중 / 복습 필요 / 완료 상태, 다음 할 일, 목표 날짜, Word 문서 위치를 기록합니다.
- 파일명·로컬 경로는 복사해서 사용합니다. OneDrive 등의 HTTP(S) 문서 링크는 새 탭에서 엽니다. 문서를 업로드하거나 사이트에 복제하지 않습니다.
- 학습 상태는 항목 전체에 공통이고, 주간 계획은 주차별 선택 목록입니다. 지난주 표시도 현재 학습 상태를 보여주며 완료 시점의 통계 기록은 아닙니다.
- 기존 위키는 별도 주소에서 유지됩니다. 로드맵 항목 ID는 원본과 동일하지만 위키의 브라우저 저장 기록은 도메인이 달라 자동 이전되지 않습니다.

## 저장과 백업

계획은 현재 도메인의 브라우저 localStorage에만 저장됩니다. 로그인·서버 동기화는 없습니다. 저장 실패를 표시하며, 실패한 변경은 완료로 표시하지 않습니다. 같은 도메인의 다른 탭에서 변경한 내용은 자동 반영합니다.

백업 저장으로 JSON 파일을 보관할 수 있습니다. 백업 불러오기는 확인 창을 거쳐 기존 계획과 합칩니다. 같은 항목의 기록은 백업의 값으로 갱신하고 주간 선택 목록은 합칩니다. 브라우저 데이터 삭제나 기기 변경 전에 백업을 저장하세요. 개인 백업을 이 공개 저장소에 커밋하지 마세요.

## 개발과 배포

외부 실행 의존성이 없는 HTML/CSS/JavaScript 앱입니다. `npm run dev`로 로컬 실행, `npm test`로 상태·백업 검증, `npm run build`로 dist를 생성합니다. Vercel은 main 브랜치의 변경을 배포합니다. 기존 정원 소스는 커밋 c718fcf에 보존되어 있습니다.

로드맵 데이터는 사용자의 기존 itaelan-wiki 원본에서 가져온 분류 목록입니다. 학습 노트 본문이나 비밀번호는 포함하지 않습니다.
